# Output Template

For API-focused solutioning and IFA output, use
[ifa-template-v4.md](ifa-template-v4.md).

For HLD or high-level architecture output, use
[hld-document-format.md](hld-document-format.md).

For glossary output, use
[glossary-document-format.md](glossary-document-format.md).

For Business Requirements Document (BRD) output, use
[brd-document-format.md](brd-document-format.md).

For ERD or data-model output, use
[erd-document-format.md](erd-document-format.md).

For broader LLD output, use
[playbook-compliance.md](playbook-compliance.md) and include only relevant LLD
sections. Detailed API request, response, and status specifications remain in IFA.
